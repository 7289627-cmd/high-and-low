# a04 report: Capacitor wrapper for iOS and Android

Patch: out/a04.patch. It covers only `app/` and `test/hlnative.js`. The sandbox copy has `/home/claude/ws/a04` paths hardcoded in build.py, run_*.sh, tests and tools, so the standard diff command also lists about 40 unrelated files. I filtered those out. No file under `src/` changed.

## What changed (all new files)
- `app/package.json` + `package-lock.json`: exact pins. Capacitor core/cli/ios/android 8.6.2, app 8.1.2, haptics 8.0.2, status-bar 8.0.4, splash-screen 8.0.2, @capacitor-community/admob 8.3.0, @revenuecat/purchases-capacitor 14.1.0, esbuild 0.28.2 (dev), typescript 5.9.3 (dev). Capacitor 8 needs Node >= 22.
- IAP choice: RevenueCat. It is a native Capacitor plugin (same pattern as the rest, mockable), handles receipts, restore and Play acknowledgement for one non-consumable without our own server. cordova-plugin-purchase has no third-party account but goes through the Cordova shim and leaves more to get right. Cost: an extra service, two public SDK keys, privacy policy wording.
- `app/capacitor.config.ts`: appId `com.example.highandlow` marked TODO(owner), appName "High & Low", webDir `www`, sky #7FD0E4 for splash/status bar/backgrounds.
- `app/sync-web.sh`: runs `build.py web`, copies `site/` to `app/www` minus lab/, sounds.html, deaths.html, *.py/*.map/*.md/_*/dotfiles, bundles the native bridge, inserts one script tag into the COPY of index.html (web build untouched).
- `app/native/hlnative.js`: defines `window.HLNative` (showInterstitial, showRewarded, buyNoAds, ownsNoAds, plus haptic and restorePurchases). Every call is wrapped in try/catch and resolves false on a missing plugin, a placeholder id or a timeout. AdMob uses Google demo ids with `npa:true` and `isTesting` while `CONFIG.TEST_MODE` is true. UMP consent runs first (`requestConsentInfo`, `showConsentForm` if REQUIRED, then `initialize` only if `canRequestAds`). Next ad is preloaded. Audio pauses around ads and on app pause (`SFX.ctx.suspend/resume`, music elements pause, `MUSIC.sync()`). It shims `navigator.vibrate` onto Haptics, so `buzz()` in main.js works on iPhone with no source change.
- `app/native/entry.js`: esbuild entry. FOUND AND FIXED a real problem: without a bundler, `Capacitor.Plugins.AdMob` etc. do not exist, because plugins register only when their JS package is imported (checked in core/dist/index.js). So the bridge is bundled with the plugin JS (41 KB).
- `app/scripts/configure-native.mjs`: idempotent. Portrait lock, AdMob app ids, AD_ID permission, GADApplicationIdentifier, SKAdNetwork (Google id only), iPad full screen. `--personalised "text"` adds NSUserTrackingUsageDescription; default adds none.
- `app/README.md`: exact commands for Xcode and Android Studio, where each id goes, pre-submission checklist, UNVERIFIED marks. `app/.gitignore`: node_modules, www.
- `test/hlnative.js`: node + jsdom with mocked `Capacitor.Plugins`.
