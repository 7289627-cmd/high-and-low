- `src/sound.js`: `SFX.GAIN` (88 keys), applied in `SFX.play` as `vol*GAIN[key]` (missing key = 1). Anti-stacking: same key within 35 ms of an already scheduled start is dropped (`DEDUPE`, compares scheduled start times, so death-scene delays work); at most 10 voices sounding at one moment, the oldest gets an 8 ms fade and stop (`MAXVOICES`). Master gain 0.8 -> DynamicsCompressor (threshold -3, knee 3, ratio 12, attack 2 ms, release 150 ms; falls back to direct connect if creation throws) -> destination. Lazy unlock, `wakeAudio`, mute, `{rate,vol,delay}` unchanged.
- `src/base.js` `DEATH_SFX`: see below. `test/sound_levels.js`. `tools/sfx_measure.py`, `sfx_process.py`, `sfx_gains.py` (reproduce csv, files and GAIN; sources read from /home/claude/hl/sounds-src).
