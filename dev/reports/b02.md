## How it works
- Offline test build (artifact.html) with real Bagel Fat One / Baloo 2 as data URIs, HL_TEST_FILL_MS=600, Practice pill hidden by one CSS rule, names Maya/Theo via localStorage/G.players (copied from a06 make_screens.py). Fonts are looked up in store/fonts, then @fontsource in node_modules (I used a scratchpad copy); not shipped.
- Real mouse input: tap Play, drag the secret slider (.5 -> .85 -> .4 -> .72), tap HIGHER, drag the ask slider (range bar cuts), Ask. A white touch dot (injected in the page, video only) shows the finger.
- Storyboard as built: home 2 s, mode tile + Play, secret pick, wheel (briefly), HIGHER, ask slider + range bar, opponent's turn (real game handoff), pedestal guess (state forced as in a06), piano death scene played in full by showScene, result sheet "+23" rating gain (showWinner with eloLast forced).
- Capture: Playwright record_video letterboxes (390x845 picture in a grey 886x1920 canvas) and the CDP screencast is capped at CSS size, so frames come from Page.captureScreenshot with clip.scale 2.27 (true 886x1920, crisp), timestamped, turned into 30 fps by ffmpeg.
- Pacing: the box was at load 9-13 on 2 CPUs, so real input took several seconds. Each storyboard segment has a target duration (TARGETS); slower segments are sped up in post (max 6x, never slowed, nothing cut). On an idle machine the speed-ups are near 1x.
- Silent AAC track added (anullsrc). So: NO real audio. Add music/sfx before submitting if wanted.
