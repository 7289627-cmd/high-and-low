# d04: rated duel result sheet

Changed (patch covers only src/main.js, src/rating.js, new src/zz_d04.css, new test/shot_result.py; the other files that showed in a raw diff of d04 vs base3 differ only by the folder path the copy rewrote, ignored):
- src/rating.js: `RANK_ART` (6 badges on a 48 px grid: sprout, magnifier, arrowhead, crosshair, eye, crown), `rankIdx`, `rankBadge`, `rankFrac`, `rankConfetti` (18 SVG beans/triangles, palette colours). `eloPill` now shows the small badge before the rank name. `eloResultHTML` renders `.er` wrapper: `.elo-res` (keeps `.d`, `b`, up/down class and final text), `.er-bar` rank bar. The old "New rank: X!" yellow text is gone (replaced by badge stamp).
- Count-up: the real number stays in the DOM as final text. A CSS `@property --n` integer animates 0.9 s ease-out and a `::after` counter draws it (class `cu`, only added if `CSS.registerProperty` exists, so old webviews just show the final number). Chip pops with overshoot easing; loss uses a small drop-in plus a slight shake on the number.
- Rank bar: same look as `.rb-track` (3 px ink, 9 px radius, 0 3px shadow), fill shows position between rank floor and next threshold (Rookie floor = 100, the minimum rating; top rank is full and yellow). Rank-up: fills to 100, flashes yellow, bar pulses, resets and fills to the new position. Rank-down: drains and refills, no ceremony. No new text.
- Rank-up stamp: badge stamps in with ring at 0.9 s, name bumps, one 18-piece burst (removed from DOM after ~3.5 s). main.js `showWinner`: after openOv, on `.er.ru` plays `sfx('d_ding')` (existing key, delay 0.95 s) and `haptic('win')` (guarded by typeof). The name is readable from frame 0.
- Poses: winner bean uses new `a-hop` (squash and stretch hop), in rated duels the loser is also drawn with `charSVG(...,'scared')` and `a-slump` (leans and sags, slow breathing). Friends/unrated games: winner only, hop. On a rated loss the falling stage confetti is not generated (no gloating).
- Reduced motion: all new animation off, final state shown (existing a-dance behaviour kept for other sheets). Death scenes, wheel, button ids/order/handlers untouched.
- CSS: `@media (max-height:640px)` shortens the stage of result sheets (`.sheet:has(.er)`) by 50 px so buttons sit higher at 320x568.

- test/shot_result.py: steps animations every 100 ms (document.getAnimations currentTime, deterministic) for win +20, loss, rank-up 1040->1062 (shown as 1040->1062 flows Rookie->Guesser), win at top rank 1650->1668, rank-down, at 390x844 and 320x568; contact sheets in test/shots/res_*.png (looked at them and iterated).
