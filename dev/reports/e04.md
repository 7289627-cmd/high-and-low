# e04: WebKit / WKWebView / old Android WebView audit
Method: STATIC audit only. Playwright WebKit is NOT installed (checked, not installed). The sandbox has no web access, so no platform docs were consulted: every support claim is from memory (H/M/L = my confidence). Syntax floor measured with acorn on the built bundle and vendor files.

## Fixed (src/zz_e04.css, small JS edits)
1. CERTAIN BUG, iPhone: build.py `reset` puts env(safe-area-inset-top/bottom) on :root AND a01 puts it on #app. Measured with env() replaced by 59/34px in Chrome: #app ran 59..903 on an 844px screen (top inset doubled, bottom 59px off screen, tray clipped). Fix zz_e04.css `:root{padding-top:0;padding-bottom:0}`; after: 0..844. (Cleanup: delete the padding from `reset` in build.py:45; env() is 0 on desktop so no web change.)
2. In the app, inviteURL() (main.js, QR and Send invite) and shareUrl() (share.js) used location.origin = capacitor://localhost or https://localhost. Now use window.HL_SITE (added in build.py config script, = SITE) when window.HLNative or protocol capacitor:. Web unchanged.
3. Send invite: navigator.share that rejects for a non-abort reason now falls back to copy (before: silent nothing).
4. sound.js backAudio(): resume AudioContext on visibilitychange/pageshow if not running (phone call/Siri leaves 'interrupted'). Existing tap-retry kept.
5. main.js: iOS only, focusout of an INPUT scrolls page back to 0,0 (keyboard close can leave WKWebView shifted).
6. c09 tablet zoom: `--zh:calc(100dvh/z)` is dropped at computed time without dvh (iOS<15.4, WebView<108) so height became auto. @supports-not override uses 100vh.
7. rotate-cover now needs aspect >1.5. Android resizes the webview for the keyboard (360x300 matched "landscape") and hid the game while typing the name/code; app is portrait-locked.

## First things to check on a real iPhone (max 12)
1. Home screen: top bar clears the notch, bottom tray clears the home indicator, no clipped content.
2. Tap once: do sounds play? Toggle the silent switch. Do sounds come back after a phone call or Siri?
3. Background the app 10 s and return: music and sfx resume.
4. Type a name and a room code: no page zoom; after closing the keyboard the page is not left shifted.
5. Drag the sliders: no page scroll or rubber band; no pinch zoom; no long-press menus.
6. Play a full duel: does the screen stay awake? (expect no).
7. Send invite then Share: the link must be the public address, not localhost; QR scans on another phone.
8. Result sheet count-up and rank bar animate; death scenes and blinking eyes/flames look right.
9. Safari Web Inspector: no CSP errors in console; sfx/music fetch ok.
10. Kill and relaunch: name, rating, mute, Remove Ads still there. Repeat after a reboot with low storage if possible.
11. iPad portrait: scale, no cut-off bottom (zoom path).
12. Android: status bar not overlapping the game; keyboard does not show the rotate-phone cover; back button.
