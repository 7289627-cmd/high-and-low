Patch: out/f02.patch (against base5; only real files: app/*, src/ads.js, src/main.js, test/hlnative.js; sandbox path-drift hunks left out). New files: app/scripts/app_csp.py, app/deeplink/{README.md,apple-app-site-association,assetlinks.json,android-intent-filter.xml}. No binaries.

## Changed
1. Keep awake: app/native/hlnative.js `HLNative.keepAwake(on)` -> plugin KeepAwake `keepAwake()/allowSleep()`, false if plugin missing. Pinned `@capacitor-community/keep-awake` 8.0.1 (peer @capacitor/core >=8, checked with npm view; iOS .v15) and imported in native/entry.js. src/main.js `keepAwake()`: one added line calls it on change (`keepAwake.n`), web wakeLock path untouched (resume.js still passes).
2. Min WebView: capacitor.config.ts `android.minWebViewVersion: 90`. Option name/default(60)/floor(55) read from the @capacitor/cli 8.6.2 typings (npm pack). iOS target: Capacitor 8.6.2 template has IPHONEOS_DEPLOYMENT_TARGET 15.0 and Swift package .iOS(.v15); Android template minSdk 24. 90 > 85 needed for supabase ES2021 syntax. Below 90 Capacitor only logs (no errorPath page set).
3. Storage mirror (hlnative.js, runs first): sync snapshot of localStorage keys, wrap Storage.prototype.setItem/removeItem (prototype, not the instance), restore missing `hl-*` keys from @capacitor/preferences 8.0.1 (pinned, imported in entry.js), reload once if anything was restored (sessionStorage `hl-mirror-reload` guard), then debounced (400 ms, also on hide/pagehide) write-through. Write-through starts only after restore, so game defaults written during the boot (e.g. new `hl-pid`) cannot overwrite the backup; if Preferences cannot be read, write-through stays off. Skipped keys: hl-host-*, hl-sec-*, hl-session, hl-sid. Keys the game writes (grep of LS.set/localStorage): hl-pid, hl-name, hl-wins, hl-lastwin, hl-look, hl-rep, hl-coins, hl-pwspent, hl-elo, hl-elo-n, hl-elo-g, hl-pend, hl-pm, hl-botrec(-last), hl-fill-seen, hl-hint-*, hl-st-*, hl-noads, hl-mute, hl-flags, hl-sid, hl-host-*, hl-sec-*, hl-session. No secrets among them. Boot hook: none exists (game script is inline and synchronous), so reload approach used. Script tag is already before the game script (sync-web.sh inserts it before vendor/supabase, which precedes the game), nothing moved.
4. Deep links: app/deeplink/ templates + steps (optional). hlnative.js listens to `appUrlOpen` and `getLaunchUrl()`, `openRoom(url)` sets `location.hash='room=ABCD'` and reloads (game reads #room= once at boot in DEEP, cannot take it later); ignored while `view==='game'`; launch URL handled once per session (loop guard).
5. CSP: reasoning in app/README. Page, bundled hlnative.js, fonts, audio and fetches are same-origin; AdMob/RevenueCat are native SDKs; Capacitor bridge is injected natively or inline ('unsafe-inline' already present, keep it); Supabase https/wss already in connect-src. No change strictly required, but sync-web.sh now runs scripts/app_csp.py on the www COPY only to add `capacitor://localhost https://localhost` to script/style/font/img/media/connect/manifest-src (insurance if 'self' does not match a custom scheme). Website build untouched.
6. app/README.md: "What changed" section + device checklist, layout table rows. src/ads.js HLNative contract comment lists keepAwake, openRoom, haptic/exit and the mirror.
